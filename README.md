# Studio

Sammlung meiner Web-Apps, veröffentlicht über **GitHub Pages**.

| App | Pfad | Beschreibung |
|---|---|---|
| 🌍 Prozeduraler Weltengenerator | `apps/world-generator/` | Landschaften aus Seed + Regeln, 2D & 3D |

## Setup

GitHub Pages aktivieren: **Settings → Pages → Branch: `main`, Ordner: `/ (root)` → Save**.

## Neue App hinzufügen

1. Neuen Unterordner unter `apps/<app-name>/` anlegen mit `index.html`
2. In der Root-`index.html` verlinken
3. Fertig – Pages updated automatisch bei jedem Push
